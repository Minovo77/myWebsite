安装方式

按照以下步骤完成工具安装，如有疑问请联系技术支持

通用 EXE 安装包

  1. 下载 EXE 安装包 到本地
  2. 双击运行安装程序，点击「下一步」
  3. 选择安装目录（默认即可），继续安装
  4. 安装完成后，桌面生成快捷方式，双击启动

ZIP 压缩包工具

  1. 下载 ZIP 压缩包 并解压
  2. 进入解压文件夹，运行 setup.exe 或 start.bat
  3. 按向导完成配置（数据库连接等）
  4. 启动工具，登录后即可使用

浏览器扩展 (CRX)

  1. 下载 CRX 文件 到本地
  2. 打开 Chrome 浏览器，进入 chrome://extensions/
  3. 开启右上角「开发者模式」
  4. 将 CRX 文件拖入页面，点击「添加扩展」
